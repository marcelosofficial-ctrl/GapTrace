# GapTrace 1.0.0

Initial local release candidate.

## Included

- concurrent DNS, TCP, and HTTP reachability probes
- seven diagnostic states
- human-readable and JSON one-shot diagnostics
- continuous CSV evidence recording
- duration-based and Ctrl+C cancellation
- strict evidence validation
- outage-event extraction
- recovery detection
- availability analysis
- average, p95, and maximum TCP latency
- low-resource validation
- standalone Windows x64 executable
- Go standard library only
- no administrator privileges required

GapTrace is a diagnostic recorder. It is not a packet sniffer, VPN, bandwidth benchmark, or traffic-interception tool.
